Guia de transcrição

Backends

  • Whisper (local) — Transcrição offline na sua máquina. Nenhum dado sai para a internet. Ideal para arquivos curtos ou quando há restrição de privacidade.
  • Gemini — Transcrição via API do Google. Requer chave GEMINI_API_KEY configurada no .env. Resultados geralmente mais precisos para português e sotaques.

Modos de processamento Gemini

  • Síncrono — A conexão fica aberta até a resposta chegar. Resultado imediato ao concluir. Limite de 30 min por chunk (arquivos maiores são divididos automaticamente).
  • Batch (assíncrono) — O arquivo é enviado e processado em segundo plano pelo Google. Você pode fechar o navegador e voltar depois. Use o botão Verificar agora para checar o status. Resultados ficam disponíveis por 48 h após a conclusão.

Modelos Whisper

  • Modelos maiores são mais precisos, mas mais lentos e ocupam mais espaço em disco.
  • O símbolo ✓ indica que o modelo já está baixado localmente.
  • Modelos marcados como Quantizado requerem token do Hugging Face (HUGGING_FACE_HUB_TOKEN) configurado no .env.

Configuração

  • Modelos Gemini disponíveis são definidos em gemini_models.toml na raiz do projeto — edite para adicionar ou atualizar modelos sem tocar no código.
  • O modelo padrão é definido por GEMINI_DEFAULT_MODEL no .env (valores: transcribe, recommended, lite, difficult).
